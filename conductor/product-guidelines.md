# Product Guidelines: Elemental Mayhem

## Visual Design & Aesthetics
- **Theme:** Sleek Dark Arcane Cyber-Fantasy.
- **Palette:** Deep obsidian/void dark backgrounds (`#0a0c10`, `#12161f`) contrasted against intensely luminous, vibrant elemental signature accents:
  - *Fire / Magma / Heat:* Radiant Amber, Solar Orange (`#ff6b35`, `#ff3838`)
  - *Water / Ice / Cold:* Cerulean, Glacial Cyan (`#00d2ff`, `#70a6ff`)
  - *Electricity / Lightning:* Ionized Gold, Electric Violet (`#ffd000`, `#c084fc`)
  - *Poison / Acid / Nature:* Toxic Emerald, Viridian Glow (`#22c55e`, `#10b981`)
  - *Void / Chaos / Death:* Eerie Magenta, Dark Amethyst (`#d946ef`, `#a855f7`)
  - *Time / Light / Life:* Prismatic White-Gold, Ethereal Pearl (`#fef08a`, `#f8fafc`)
- **UI Surfaces:** Semi-transparent frosted glass cards (`backdrop-filter: blur()`), sharp borders with subtle elemental glow rings, and modern typography (Outfit / Inter / Fira Code for combat numbers).
- **Animations & Effects:** Rich canvas particle systems, smooth CSS transitions, glowing spell trajectory arcs, and dynamic tile hazard pulsing.

## Voice, Tone & Lore
- **Tone:** Esoteric, Arcane, and Gritty Tactical.
- **Vocabulary:** Evocative elemental concepts (Catalyst, Affinity, Dissolution, Superconduction, Superheat, Entropic Resonance).
- **In-Game Text:** Punchy, atmospheric ability descriptions paired with crystal-clear mathematical mechanics in tooltips.

## UX & Tactical Clarity
- **Pre-Execution Previews:** Hovering over target tiles or selecting an ability immediately previews movement path, action point cost, expected damage range, and resulting elemental reactions before committing the action.
- **Grid Readability:** Explicit visual distinction between walkable tiles, obstacles, hazardous terrain (e.g., Burning Tile, Electrified Water), and unit aura zones.
- **Combat Feedback:** Floating combat numbers with elemental iconography, clear status effect badges with duration countdowns, and a scrollable combat log recording all tactical events.
- **Accessibility & Controls:** Full mouse/pointer interactivity, keyboard hotkeys (`1`-`5` for abilities, `Space` for End Turn, `Esc` for Deselect), high-contrast UI mode support.
