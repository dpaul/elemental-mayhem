# Product Definition: Elemental Mayhem

## Vision
Elemental Mayhem is a turn-based tactical arena combat game built for the web. The game focuses intensely on deep tactical grid battles, positioning, and strategic mastery over 42 distinct elemental forces. The core loop centers around an escalating Arena Gauntlet where players fight tactical combat rounds against elemental adversaries, earn Experience & Elemental Essence through tactical performance, and customize their hero's elemental build between rounds.

## Core Pillars
1. **Tactical Grid Combat:** Turn-based battles on compact interactive grid arenas where positioning, line-of-sight, obstacle manipulation, movement ranges, and elemental hazard tiles determine tactical victory.
2. **42-Element Reaction & Affinity System:** Elements feature dual-layer depth:
   - *Affinities & Weaknesses:* Direct damage multipliers, resistances, and vulnerabilities across elemental groups.
   - *Reactions & Fusions:* Emergent battlefield interactions when elements collide on characters or tiles (e.g., Water + Lightning = electrifying conductivity, Fire + Poison = volatile combustions).
3. **Performance-Driven Custom Progression:** 
   - Combat performance (kills, multi-element reactions triggered, tactical bonuses) awards XP and Elemental Essence.
   - Post-round phase provides customizable progression: spending points on targeted elemental skill trees, upgrading active abilities, infusing spells with secondary elements, and purchasing passive relics.
4. **Snappy & Responsive Web Experience:** Fast-loading, responsive web app featuring clear tactical visual indicators, particle-rich elemental FX, and intuitive mouse/keyboard/touch grid controls.

## Core Gameplay Loop
1. **Arena Deployment:** Spawn into a grid arena with dynamic terrain hazards and distinct enemy compositions.
2. **Tactical Turn Resolution:** Move, cast elemental spells, trigger tile reactions, manage Action Points (AP), and defeat enemy forces.
3. **Performance Scoring & Rewards:** Calculate XP and Elemental Essence based on combat efficiency and reactions triggered.
4. **Custom Upgrade Phase:** Spend earned resources in the post-round armory/shrine to unlock specific spells, upgrade element mastery tiers, or acquire tactical relics.
5. **Arena Escalation:** Advance to higher arena rounds with elite modifiers, shifting environmental hazards, and boss challenges.

## MVP Scope
- Core turn-based grid combat engine (movement, action points, range/AoE targeting, terrain hazards).
- Initial roster of key elemental archetypes with working affinities, tile hazard states, and fundamental reactions.
- Combat scoring system (XP/Essence calculation) and customizable post-round upgrade shop/tree.
- Arena escalation manager tracking rounds, enemy waves, and win/loss states.
- Clean web interface with tactical grid rendering, combat logs, action bar, and visual effects.
